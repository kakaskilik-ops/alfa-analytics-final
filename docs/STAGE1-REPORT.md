# Отчёт о доработке — 12 ноября 2026

Рабочие исходники: `/workspace/work/alfa`. Это продолжение приложенного проекта. Новый проект с нуля не создавался. Ничего не опубликовано, удалённая production-база не изменена, git push и платные API-запросы не выполнялись.

## 1. Аудит и исправления

В исходном архиве 92 файла. Обнаружена одна копия React-приложения в самой глубокой папке и четыре последовательных набора Supabase-файлов на разных уровнях вложенности. За основу интерфейса взята единственная папка с package.json и src, для сервера — последний внешний набор миграций 20261109141643–20261109141810. Сформирована единая рабочая структура без повторного вложения архивов. Контрольные суммы исходных файлов: ARCHIVE-INVENTORY.json. Исходный архив сохранён.

Удалены генератор случайных рядов, масштабирование демонстрационной истории под реальную цену и фиктивные валютные fallback-курсы. История проверяется по спецификации, валюте, единице и периоду. Исправлен перевод тройских унций и фунтов. Устаревшие данные не считаются актуальными. Отсутствие цены — null и явное состояние интерфейса.

Вычисление средней больше не смешивает разные металлы, марки, формы, регионы, рынки, составы, типы цен, валюты и единицы. Перепечатки одного первоисточника можно объединить independence_id. Необоснованные веса качества не используются в средневзвешенной. Оценка требует двух независимых источников; подозрительные значения исключаются и учитываются в счётчике.

Старый сборщик ошибочно считал HRC ценой за метрическую тонну; mapping отключён. История Yahoo ранее сохранялась в исходных единицах, а интерфейс считал её USD/кг. Новая история нормализуется и имеет ключ спецификации. Старая история без подтверждённого ключа помечается недоступной новой миграцией. Нулевая цена запрещена для новых записей. Исходные строки не удаляются.

В исходном внешнем .env были URL Supabase и публичный anon JWT, а не найденный service-role ключ. Старые значения не перенесены. Клиентская конфигурация отбрасывает известный формат серверного ключа и привилегированные JWT. Неиспользуемый DemoBadge удалён после проверки импортов. Снимки прежних deployment-state не включены в рабочую конфигурацию. Адрес прежнего Supabase-проекта удалён из cron; расписание теперь настраивается через Vault отдельно.

## 2. Добавленные функции

Каталог: 129 материалов, 9 категорий, все запрошенные марки. Существующий «Лом титана» получает синоним «титановый лом», вместо дублирования карточки. Состав неоднозначных марок не выдумывается. Сохраняются исходные карточки, поиск, категории и избранное; добавлена сортировка.

Аналитика: отдельная страница, выбор до четырёх материалов через доступные на телефоне checkbox, периоды, исторические графики, динамика и волатильность, группы регионов/спецификаций, CSV. Существующий Excel XML-экспорт сохранён, добавлено экранирование XML и защита CSV от формул.

Источники: реестр, статусы, даты, мониторинг, лицензирование, описание методики, честное состояние при недоступной БД. Обзор не показывает фиктивные индекс 100 или рост 0% при отсутствии ряда. Корзина индекса использует только общие даты подтверждённых рядов без интерполяции.

ИИ: серверный ai-analyze, проверка JWT и пользователя, 10 запросов пользователя в час в атомарном SQL-счётчике, ограничение ввода, CORS выбранного домена, timeout, безопасные ошибки, фактические данные БД и источники в ответе. Есть вход по почтовой ссылке. Без ключа и данных выдуманных ответов нет. Модель не вызывалась в ходе проверки.

Интеграции: контракт QuoteProvider и endpoint ingest-quotes для доверенного серверного импорта; проверка спецификаций, дат, единиц, ссылок, дублей, предельного объёма пакета. Исходный Frankfurter-адаптер сохранён, Yahoo исправлен и выключен по умолчанию.

Безопасность и UX: ErrorBoundary, загрузка/ошибка/повтор, timeout запросов БД, закрытые внутренние подробности ошибок, RLS и права чтения, секреты только на сервере. Модальное окно перенесено в portal, добавлены блокировка фона, удержание и восстановление фокуса, Escape. Исправлены переполнения каталога и периодов на мобильном экране. Навигация хранится в hash URL, страницы загружаются по требованию.

## 5. Что осталось и ограничения

Реальных ключей, выбранной инфраструктуры и договорных API нет. Удалённый Supabase, Auth/SMTP, Vault, pg_cron/pg_net, реальные котировки, источник RUB, OpenAI, DNS/TLS и конфигурация Caddy в этой среде не проверены. До запуска требуется staging-проверка с ними. Миграции только подготовлены и проверены локально; удалёнными применёнными они не объявляются.

Лицензированные адаптеры LME/CME/SHFE/LBMA требуют конкретной документации и прав доступа. Подготовлен общий контракт/импорт, а не неподтверждённые реализации закрытых API. Универсальный импорт истории через endpoint не реализован: история поступает от существующего сборщика либо будущей доверенной логики поставщика. Импорт ProviderQuote сейчас принимает USD; другие валюты требуют серверной конвертации с аудитом.

Независимость источников, состав, условия поставки, НДС, объём партии и достоверность grade требуют проверки оператором. Методика v1 консервативная; для публикации официального индекса нужны фиксированные состав и календарь. Хранилища индексов и аналитических расчётов подготовлены, автоматическая материализация расчётов в них не включена. ИИ ограничен по пользователю, глобальный денежный бюджет и антифрод массовых регистраций не реализованы. Платёжных функций нет.

## 6. Что подключить

Supabase/PostgreSQL и Auth/SMTP; выбранные открытые/лицензированные источники по регионам; подтверждённые FX, включая отдельного поставщика RUB; OpenAI при необходимости. Yahoo только после проверки прав и явного включения. Для марок и лома нужны реальные поставщики с сертификатами партий; цены чистого металла не заменяют цены сплавов.
