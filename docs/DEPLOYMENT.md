## Функции и расписания

| Функция                 | Назначение                                                         | Авторизация                           |
| ----------------------- | ------------------------------------------------------------------ | ------------------------------------- |
| collect-fx              | Frankfurter v2, последние 7 дней; ручной backfill до 31 дня        | collector token                       |
| collect-quotes          | Одобренные canonical JSON gateways, до 5 источников за запуск      | collector token                       |
| compute-orientations    | Общий с интерфейсом алгоритм, расчёты и дневные снимки истории     | collector token                       |
| collect-news            | Одобренные RSS/Atom/JSON, дедупликация, переводы при включении API | collector token                       |
| ingest-quotes           | Проверенный импорт котировок                                       | collector token                       |
| ingest-regional-history | Импорт разрешённой истории с коммерческим ключом                   | collector token                       |
| ai-analyze              | Анализ подтверждённых данных и новостей                            | JWT пользователя + серверная проверка |
| collect-market-data     | Сохранённый старый FX-сборщик; не включать вместе с новым          | collector token                       |

`ops/activate-automation.sql`: FX ежечасно на 7-й минуте, котировки в 0/30, новости в 5/35, расчёты в 10/40. UTC, без домашнего компьютера. Токен берётся из Vault при каждом вызове. Миграция создаёт токен; общее расписание уже включено отдельным инфраструктурным шагом. Повторная активация обновляет только именованные задания `alfa-*`. Не активировать одновременно старые `ops/schedule.sql` / `ops/news-schedule.sql`.

FX/quotes/analytics используют атомарную блокировку, минимальные интервалы и 5-минутную аренду; новости имеют собственную атомарную защиту. `automation_runs` содержит безопасные статусы, реальные числа вставленных FX/quotes и коды ошибок; `news_ingestion_runs` — новости. Сырые ответы в `ingestion_payloads` доступны только серверу. При проверке автоматизации подтвердить два запуска, запрет повторного вызова в cooldown, отсутствие секретов в логах и записи в `cron.job_run_details`. Тайм-аут HTTP не равен успешной обработке: проверять журнал функции и таблицы.

История металлов сохраняется только по реальным наблюдениям, с точным ключом продукта/источника/региона. Дневной снимок отражает доступные приложению наблюдения, не полный биржевой OHLC. Существующие дневные записи не перезаписываются; для полной истории нужен разрешённый historical feed. Предел одного расчёта — 1000 последних наблюдений за четыре дня; достижение предела даёт partial. Пропуски не интерполируются.

## Источники и расходы

Frankfurter v2 проверен реальным HTTP-запросом и парсером для USD/EUR/RUB/CNY. Это blended расчётные справочные курсы с датами первичных провайдеров. Автоматический сбор реализован, удалённое сохранение проверено: 84 курса и исходный ответ. Нет ключа и платных вызовов. История FX поддерживается, начальное окно 7 дней; произвольная многолетняя история не загружена. Не публикуется копия скачанного ответа как production seed.

Котировки: доступных лицензированных ключей нет. LME/CME/SHFE/Argus не подключены к реальному потоку. Конфигурация адаптеров хранится в приватной `analytics_internal.quote_adapters`, выключена по умолчанию и требует license_reference, approved_at и allowlist. Это контракт canonical JSON, а не готовое преобразование любого API Argus. Для конкретного поставщика понадобится mapping его продукта/спецификации. Платные обращения дополнительно требуют `ALLOW_LICENSED_QUOTE_REQUESTS=true`. Приватная таблица `reference_benchmarks` и функция сравнения подготовлены для законного Argus-доступа; публикация эталонных цен не реализована.

OpenAI: задать Edge secrets из `supabase/.env.example`, выбрать модель и явно разрешить расходы положительным `AI_DAILY_TOKEN_LIMIT`. По умолчанию 0 запрещает платные запросы. Не класть ключ в VITE_*. Проверить Auth-пользователя и ответ с реальными citations; ответы модели не гарантируют будущую цену.
