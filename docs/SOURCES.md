## Товарные группы Comtrade

HS2022: W 810110 (порошки), Mo 810210 (порошки), FeMo 720270, FeW 720280 (**включает ферросиликовольфрам**), Sn 800110, Zn 790111, Cu 740311, Al 760110, Cr 811221, Co 810520 (**включает штейны и промежуточные продукты**), Zr 810921 (ограничение Hf), Ta 810320. Полные подписи в `shared/trade.ts`. Для Nb группа 811292 включает другие металлы — не используется. Наличие сборщика не означает наличие данных каждой группы.

## Бесплатный ИИ

- Основной: OpenRouter, `google/gemma-4-31b-it:free`, резервный маршрут `openrouter/free`. Каталог моделей реально получен HTTP 200. Это инженерный выбор по доступности, русскому языку и структурированному ответу; финансовый benchmark не проведён.
- [Free router](https://openrouter.ai/docs/guides/routing/routers/free-router), [выбор провайдера](https://openrouter.ai/docs/guides/routing/provider-selection), [лимиты](https://openrouter.ai/docs/api-reference/limits). На момент проверки бесплатные маршруты: 20 запросов/минуту, 50/сутки без пополнения; доступность меняется. В запросе жёсткие нулевые `max_price`, только `:free`, запрет сбора данных и ограниченный резерв. Это может уменьшить доступность — в таком случае интерфейс сообщает ошибку, платного fallback нет.
- Необязательный отдельный резерв: Groq `qwen/qwen3.8-27b`, только с ключом и `GROQ_FREE_TIER_CONFIRMED=true` после проверки владельцем бесплатного тарифа. [Free-plan limits](https://console.groq.com/docs/rate-limits): текущая таблица 30 RPM / 1000 RPD / 8000 TPM / 200000 TPD для этой модели. Биллинг не активируется кодом.
- [Gemini](https://ai.google.dev/gemini-api/docs/pricing) и [допустимые регионы](https://ai.google.dev/gemini-api/docs/available-regions) проверены как альтернатива. Наличие бесплатных моделей не отменяет ограничений страны аккаунта; Россия не входит в опубликованный список. Обход региона не предлагается; основной маршрут выбран без предположения о местоположении владельца.
- Общий серверный бюджет: по умолчанию 20 попыток/сутки, максимум 40; до 4/минуту. Консервативная резервация по 16000 токенов при общем лимите 160000/сутки дополнительно ограничивает примерно десятью попытками. Все fallback резервируются отдельно. Автоотчёты максимум два/сутки, кеш по набору доказательств, блокировка параллельной одинаковой работы.
- Реального запроса к модели **не было**: `ai-status` вернул `configured=false`, `verifiedAt=null`; задание отчётов — `ai_not_configured`. Транспортные тесты используют mocks и не подтверждают работу внешней модели.
